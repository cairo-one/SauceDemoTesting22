# SauceDemoTesting22 – Selenium Automation Testing

## 📌 Project Overview

SauceDemoTesting22 is a web automation testing project developed using **Java, Selenium WebDriver, TestNG, and Maven**.

The project is designed to automate testing of the SauceDemo website and practice web application testing using Selenium.

**Application Under Test:** https://www.saucedemo.com/

## 🛠️ Technologies Used

- **Programming Language:** Java 17
- **Automation Tool:** Selenium WebDriver 4.27.0
- **Testing Framework:** TestNG 7.10.2
- **Build Tool:** Maven
- **IDE:** Eclipse / IntelliJ IDEA
- **Browser:** Google Chrome
- **Version Control:** Git and GitHub

## ⚙️ Prerequisites

Before running this project, make sure you have installed:

1. Java JDK 17 or above
2. Eclipse or IntelliJ IDEA
3. Apache Maven
4. Google Chrome Browser
5. Git

## 🚀 Installation and Setup

**Step 1: Clone the Repository**

```bash
git clone https://github.com/cairo-one/SauceDemoTesting22.git
```

**Step 2: Open the Project**

Open the cloned project in Eclipse or IntelliJ IDEA as a Maven project.

**Step 3: Install Dependencies**

Run the following command:

```bash
mvn clean install
```

**Step 4: Execute Test Cases**

Run:

```bash
mvn test
```
